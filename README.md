# ALSOS — Public Website

> ἄλσος — grove, sacred grove.

로그인 이전의 브랜드·제품 소개 사이트입니다. 실제 학습, Lab 실행, 대시보드, XP 처리,
Garden 편집은 **이 저장소의 범위가 아닙니다** — `app.alsos.io`에서 제공됩니다.

```
www.alsos.io   공개 소개 사이트   ← 이 저장소
app.alsos.io   학습 플랫폼        별도 애플리케이션
```

---

## 실행

```bash
npm install
npm run assets:hero   # 히어로 아트 생성 (최초 1회, 약 1분)
npm run dev
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm run typecheck` | TypeScript strict 검사 |
| `npm test` | 유닛 테스트 (Vitest) |
| `npm run test:e2e` | 브라우저 테스트 (Playwright) |
| `npm run assets:hero` | 히어로 아트·성장 스프라이트 재생성 |

### 스티플링 — 격자가 아니라 점

플레이트는 사진도, 픽셀 격자도 아닙니다. **62만 개의 개별 점**입니다. 어디에도 스냅되지
않으므로 형태가 곡선을 유지합니다.

세 가지 원칙:

**색은 색조가 아니라 화성(harmony)입니다.** 램프가 올라가면서 색상이 회전합니다 —
차가운 청록 그림자에서 옥색, 잎사귀를 거쳐 따뜻한 금빛으로. 단색 이미지는 분위기를 낼 수는
있어도 빛날 수는 없습니다. 광휘는 **차가운 어둠과 따뜻한 빛의 대비**이기 때문입니다.

**밀도가 곧 드로잉입니다.** 점은 빛이 모이는 곳에 몰리고 어둠 속으로 흩어집니다.
눈은 윤곽이 아니라 덩어리와 공기를 읽습니다. 점 크기는 거리에 따라 줄어들고,
그것이 숲의 깊이를 만듭니다.

**규모가 압도합니다.** 기둥들은 프레임 양옆을 넘어가고, 빛은 화면 위쪽 바깥에서 떨어지며,
중앙의 나무는 그 모든 것에 비해 작습니다.

```
공기(대기 원근) → 수관 → 기둥(뒤에서 앞으로) → 빛줄기 → 안개 → 사진(유기적 얼룩)
  → 확장 Reinhard 숄더 → 램프 → 62만 점 스티플
```

> 대기 원근이 핵심입니다. 거리는 숲을 **어둡게** 하지 않고 **밝게** 합니다 — 안개가 빛을
> 산란시키니까요. 공기를 먼저 만들고 거기서 가까운 실루엣을 도려내야 깊이가 생깁니다.
> 거리에 따라 어둡게만 하면 평평한 벽이 됩니다.

> 모든 항이 가산이므로 밝은 영역은 1을 훌쩍 넘고, 램프가 그걸 태양에 고정하면
> 부드러운 감쇠가 **딱딱한 흰 쐐기**로 변합니다. 확장 Reinhard(화이트 포인트가 있는)로
> 숄더를 굴려야 빛이 아무리 쌓여도 부드럽게 남습니다.

사진은 구조가 아니라 **유기적 얼룩**으로만 곱해집니다. 숲 자체는 합성해서 만듭니다 —
그래야 구도, 깊이, 빛을 완전히 통제할 수 있습니다.

## 좌표 기준

모든 위치는 **1536×605 canonical reference**(§6)에서 나온 값입니다.
`public/assets/hero/manifest.json`이 좌표 계약을 담고 있어서
개발자가 위치를 눈으로 추정하지 않습니다.

```json
{
  "referenceViewport": { "width": 1536, "height": 605 },
  "focalPoint": { "x": 0.5566, "y": 0.4463 },
  "copySafeArea": { "x": 0.0521, "y": 0.2727, "width": 0.235, "height": 0.47 },
  "metricsSafeArea": { "x": 0.918, "y": 0.3355, "width": 0.065, "height": 0.38 }
}
```

### 개발용 오버레이

개발 빌드에서만 동작합니다.

```
?referenceOverlay=1   레퍼런스를 50%로 겹쳐 표시
```

| 키 | 동작 |
| --- | --- |
| `R` | 오버레이 표시 전환 |
| `D` | difference 모드 — 검게 나오면 일치, 밝으면 어긋남 |
| `G` | 8px 그리드 |
| `M` | 모션 정지 |

## 데이터에 관한 원칙

**가짜 지표를 쓰지 않습니다.** 우측 레일에는 학습자 수·성공률·Lab 수 대신
세 개의 제품 개념(STRUCTURED PATHS / HANDS-ON PRACTICE / LIVING PROFILE)을 둡니다.
실제 데이터가 검증되기 전까지 숫자 지표는 노출하지 않으며, 테스트가 이를 강제합니다.

---

## 접근성

* 모든 카피와 링크가 DOM에 존재합니다. 장식 레이어는 `aria-hidden`입니다.
* JavaScript 없이도 헤드라인과 CTA가 표시됩니다.
* 스프라이트가 로드되지 않아도 정적 포스터로 히어로가 완결됩니다.
* `prefers-reduced-motion: reduce`에서 나무는 최종 상태로 정지합니다.
* 포커스 링을 제거하지 않으며, 첫 탭 스톱은 건너뛰기 링크입니다.

## 알려진 범위

* 히어로 아트는 시드 기반 **절차적 생성**입니다. §8의 회화 에셋으로 교체할 때는
  manifest 계약만 맞추면 컴포넌트를 수정하지 않아도 됩니다.
* 디스플레이 서체는 커스텀 "ALSOS Grid"가 제작되기 전까지 Pixelify Sans를 대역으로 씁니다.
  8비트 게임 서체가 아니라 픽셀 그리드 위의 정상적인 타이포 비례를 가진 face입니다 —
  §5.1이 사이트 전체가 고전 게임처럼 보이는 것을 경계합니다.
  워드마크는 서체가 아니라 12×12 모듈 그리드 위의 SVG 패스입니다.
* 태블릿·모바일은 전용 아트가 나오는 PR3에서 다룹니다.
